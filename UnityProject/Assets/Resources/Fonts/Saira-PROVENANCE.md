# Saira HUD fonts

Source: https://github.com/google/fonts/tree/main/ofl/saira
Upstream designer: Omnibus-Type / Héctor Gatti.
License: accompanying Saira-OFL.txt (SIL OFL 1.1).

Static native-width italic instances made with fontTools varLib.instancer:
- Saira-BlackItalic.ttf: wght=900 wdth=100, --update-name-table.
- Saira-MediumItalic.ttf: wght=500 wdth=100, --update-name-table.

Source Saira-Italic[wdth,wght].ttf SHA-256:

No outline deformation or synthetic bold/italic is used in-game. These files serve only the arcade race HUD; existing menu fonts remain unchanged.
