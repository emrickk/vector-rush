Their original repeat mode, 512-square source resolution, mipmaps, trilinear filtering, anisotropy and ownership remain intact. No copied or amplified tiny-noise map is created.

The original sRGB albedo texture goes directly into `_DetailAlbedoMap`. The main atlas is now a **linear** multiplier, nominally .5. URP's `_DETAIL_MULX2` multiplies the sampled original detail albedo by2, so .5 main ×2 ×original recovers the original albedo at the boundary without a gamma-incorrect texture conversion. Inside the region, a road-coordinate multiplier `.7488..1` selectively darkens matte patches and leaves satin islands near control albedo; it never paints a bright streak or raises the full-road base color. Existing service-polish paths remain deck-coordinate functions, with a more decisive smooth transition into worn islands. Metallic stays zero; nominal mask endpoints remain .35..50 with .90 multiplier.

The broad normal now uses only the coherent metric relief at x-frequency .55 and longitudinal-frequency .24, amplitude .14; the small secondary component is removed because fine detail is retained separately. This is a source-dependent normal response, not emission or a painted camera highlight. A 12m fade brings the broad normal to exactly flat `(0,0,1)` and main albedo to .5 at either end. It never fades toward a second copy of the original normal. URP's RNM detail blend then returns the original normal direction at a flat boundary, apart from ordinary floating-point/filtering differences. The roughness boundary still samples the original mask into a coarse atlas; exact original texel/mip identity for that mask is **not** claimed and must be inspected natively.

With detail sampled independently, broad atlas resolution is256x1024 for opening and256x256 for gallery. Main albedo and normal atlases use RGBAHalf (linear), which represents .5 exactly and avoids quantizing shallow normal slopes into 8-bit steps. Smoothness remains linear RGBA32. All atlases retain mipmaps, clamp, trilinear and anisotropy8. Estimated regional texture mip storage is8.333MiB versus20.000MiB in opening-01; this excludes driver overhead. The shader adds detail albedo/normal/mask sampling and RNM operations. Lower texture memory is **not** a performance pass.
