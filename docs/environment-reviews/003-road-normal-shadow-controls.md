# Road diagnostic 003: normal and shadow controls do not establish a correction

Independent review, 2026-09-08. **Keep the original road normals and lighting settings.** The 17 native views in `road-surface-02` do not show a clear corrective advantage for continuous ribbon normals or disabled sun shadows. The intentionally incorrect global-up normals visibly redirect the highlight, but that is not a suitable banked-road finish. The strong diagonal polygon from the first diagnostic is already much less distinct in this run's baseline, which limits the test's ability to identify its cause.

## Scope and comparison validity

All 17 PNGs were directly inspected, alongside the [native report](../../evidence/road-surface-02/road-surface-evidence.json) and [capture source](../../UnityProject/Assets/Scripts/RoadSurfaceEvidence.cs). The report records completion on Unity 6000.6.0f1, Metal, Apple M2 Max, from 08:19:33 to 08:20:19 UTC. Every image is 1920 × 1080 and has the same recorded camera position and rotation, race time 35.3600731, and track progress 0.8850534. FOV is 70.06416°. Matching is valid **within this run**.

This is not the same pose or scene as [diagnostic 002](002-road-diagnostic.md). The first run used race time 35.3500748 and progress 0.8847515, and the camera transforms differ. Gallery geometry and lighting also changed. The current baseline has 92 enabled non-directional lights; the first had 98. A lower-contrast polygon here cannot be attributed to a normal or shadow control before those controls are applied. No cross-run pixel comparison or correction percentage is claimed.

The source restores materials, original normals, light enabled states and shadow settings between conditions. The compared pairs below have identical recorded material descriptions and non-directional-light lists. Vertices, topology, UVs and tangents remain fixed. Completion establishes the capture sequence, not a full road-quality or motion pass.

The continuous-normal control estimates the road surface's longitudinal derivative at each lateral offset, using `Track.Evaluate(progress ± 0.00005)`, and crosses it with local right. It preserves bank information rather than forcing global up. That is a meaningful diagnostic candidate. It still needs positive evidence before replacing the current normals. Tangents remain the originals, so view 14 is not validation of a newly authored normal-and-tangent basis.

The shadow control changes `RenderSettings.sun.shadows`; [world construction](../../UnityProject/Assets/Scripts/World/WorldBuilder.cs) assigns that sun to `Midnight soft key`. One reporting limitation remains: each view stores the requested `noSunShadows` flag, not a fresh readback of the sun identity and effective shadow mode. Record those actual values if this comparison is repeated for a definitive exclusion. The current report supports that the control was requested and the source implements it, while the images supply the visual result.

## Other controls and disposition

The remaining [01 constant-smoothness](../../evidence/road-surface-02/01-constant-smoothness-map-disabled.png), [02 normal-disabled](../../evidence/road-surface-02/02-normal-disabled.png), [03 both-disabled](../../evidence/road-surface-02/03-both-disabled.png), and [06 constant-mask](../../evidence/road-surface-02/06-constant-mask-original-keywords.png) views alter texture variation and highlight width without establishing the old hard polygon as the same target. The normal-disabled view again differs substantially from the original-keyword zero-scale control; that difference must not be relabeled proof of incorrect normal-map encoding. No missing-shader pink output is visible, but the existing shader-variant qualification remains.

The [first selected light](../../evidence/road-surface-02/08-selected-light-1.png), [second selected light](../../evidence/road-surface-02/08-selected-light-2.png), and [combined lights](../../evidence/road-surface-02/09-selected-lights-combined.png) mainly change warm illumination around the craft and road. These are now two warm gallery pools, not the cool/warm pair selected in the first run. Their identities and ranking should not be carried across runs.

Do not ship either global-up normals or disabled sun shadows from this result. Keep the original normals while reviewing the full environment passage. Preserve the first run as an unresolved failure reference. If root-cause diagnosis continues, first reproduce a conspicuous boundary with its scene, lighting and pose locked; then rerun one selected normal or shadow pair against that visible target. Another collection of controls against an already weak target would not justify a causal claim.

The forthcoming five-view and continuous environment review is separate. None of these stationary controls establishes that the road remains coherent throughout ordinary or boosted motion.
