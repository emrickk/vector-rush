## Delivered source contract

- `AAAExemplar.cs`: ScriptableObject staging recipe with revision, a non-wrapping interval of at most 15% of the lap, explicit prefab placements, semantic group labels and exact source-material-slot bindings. No authored color, roughness, light intensity, placement coordinate or geometry recipe is invented by the hook.
- `AAABaselineIntegration.cs`: `TryAttach(world, Track)` returns immediately when no flag or `off` is supplied. Only `opening` and `gallery` are supported. Missing staging assets log and leave the baseline intact. Conflicting older opening-finish flags are rejected. It validates the whole recipe before attaching, assembles inactive staging, applies prepared material references only on instances, and restores visual states on failure, disable or destruction.
- `AAAExemplarValidation.cs`: read-only editor preflight for persistent meshes/materials, normals/UV0/tangents, material keywords and color/data/normal texture import contracts. It never calls `Prepare`, saves scenes, changes pipeline settings or imports/reimports assets. Missing optional payloads are reported as absent, not as successful payload validation.
- Each new script has its own `.meta`. The containing `AAA.meta` files would be outside the explicitly owned directories, so **parent must create/preserve both folder metas** during integration. No files outside the three assigned paths were authored by this worker.

Runtime accepts Transform, MeshFilter, MeshRenderer, LODGroup and local Light components only. Collider, Rigidbody, Camera, volume/global-light and executable prefab components are rejected before instantiation. This preserves baseline physics/camera systems; it does not establish camera clearance or playable appearance. Prepared materials must use URP/Lit; custom shaders require a deliberate contract extension. The loader never infers material semantics from substrings, recolors the world, changes URP globals, or changes original light intensities.

Placement convention is imported Unity local +X right, +Y up, +Z forward, in metres. `followBank=true` uses the course bank, suitable for track-attached gallery modules. `false` projects the heading onto world up, suitable for upright buildings. Offset is expressed in that route frame. `rotationDegrees` corrects the actual imported asset orientation; positive scale preserves source scale. Degenerate forward/up frames have an orthogonal fallback. Verify the imported road-facing side in native views before adoption.

Replacement is opt-in per placement: exact `replaceRendererNames` / `replaceLightNames`, a semantic group label, and a `replacementVolume` expressed in the imported prefab root's local coordinates. Empty name arrays retain everything. A renderer is hidden only if all eight corners of its world AABB fit inside that volume; any collider on its GameObject protects it. Only matched local lights inside the volume can be hidden. Original enabled states are restored, never deleted. Whole-lap combined meshes usually fail containment deliberately; do not expand the volume to hide them. Parent must split legacy geometry into bounded semantic pieces in a later separately reviewed step if a gallery cannot replace cleanly. Merely adding duplicate gallery surfaces will cause intersections and is not acceptable evidence.
